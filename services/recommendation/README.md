# Recommendation Service

## Описание
Сервис рекомендаций (Recommendation Service) отвечает за хранение информации о фильмах и формирование подборок для сессий пользователей. Он является частью микросервисной архитектуры проекта FlickToPick.

## Функциональность
- Предоставление списка фильмов для сессии.
- Выдача следующего фильма для рекомендации (например, когда текущий фильм отклонен).
- Хранение данных о фильмах в собственной базе данных.
- Валидация сессии через Session Service (опционально/в разработке).

## Технологический стек
- **Язык**: Python 3.12+
- **Фреймворк**: FastAPI
- **ORM**: SQLAlchemy
- **База данных**: PostgreSQL (в продакшене), SQLite (для разработки/тестов)

## API Эндпоинты

### 1. Получение списка фильмов
**GET** `/movies`

Параметры:
- `session` (query, string): Код сессии.

Ответ:
- `200 OK`: Список объектов фильмов.
- `403 Forbidden`: Если сессия недействительна.

Пример ответа:
```json
[
  {
    "title": "Inception",
    "genre": "Sci-Fi",
    "duration_minutes": 148,
    "rating": 8.8,
    "description": "...",
    "poster_url": "...",
    "id": 1,
    "is_available": true
  }
]
```

### 2. Получение следующего фильма
**GET** `/recommendation/next`

Параметры:
- `session` (query, string): Код сессии.
- `current_movie` (query, int): ID текущего фильма.

Ответ:
- `200 OK`: Объект следующего фильма.
- `404 Not Found`: Если фильмы закончились.

### 3. Проверка здоровья
**GET** `/health`

Ответ:
- `{"status": "ok"}`

## Запуск

### Локально
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   uvicorn app.main:app --reload --port 8002
   ```

### Конфигурация
Сервис использует переменные окружения:
- `DATABASE_URL`: Строка подключения к БД (по умолчанию `sqlite:///./movies.db`).
- `SESSION_SERVICE_URL`: URL сервиса сессий (по умолчанию `http://localhost:8001`).
- `SKIP_SESSION_CHECK`: Если `true`, пропускает проверку сессии (для разработки).

## Тестирование
Для запуска тестов выполните:
```bash
pytest
```
Тесты используют изолированную файловую базу данных SQLite.
